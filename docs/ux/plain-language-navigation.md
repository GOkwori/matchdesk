# Clear language and demo safety

MatchDesk is a football-storytelling demonstration. All match events, clubs, players and sample activity are invented.

## What visitors can explore

- **Watch and explore:** Match overview, Watch the replay, Key moments, Players, Match analysis, Match stories and Check the facts.
- **Studio demo:** How AI helps, Review drafts, Write a match story and Try demo publishing. These pages use fictional examples and browser-only demo actions.
- **Advanced examples:** The fact-checking benchmark, video detection experiment, broadcast overlay and developer tools are optional. They are not prerequisites for enjoying the match.

## Meaning of common labels

| Label | Meaning |
| --- | --- |
| Check the facts | Compare a statement with the event log rather than accept a guess |
| How AI helps | Show what the four specialist models suggest and what the verifier accepts |
| Review drafts | Inspect a pretend editorial queue and fix a sample story |
| Ready for demo review | This device marked a sample draft ready; no actual editor was notified |
| Try demo publishing | Simulate sign-off and retries in the browser; no real destination receives content |
| Demo activity | Fictional seeded activity plus local actions, **not** authenticated audit evidence |

## Safety and trust

- The visible `DP` identity is a **fictional demo producer**, not a signed-in person.
- Browser-local approvals, audit records and publication receipts do **not** prove genuine producer review, publishing or competition submission.
- Current source and last deployed Azure revision may differ. See the [judging guide](../competition/judging-guide.md) and the exact-SHA GitHub Actions records before making deployment claims.
- The seven-step guided journey, exact routes, registered metrics, deterministic verifier and security gates are preserved.
- The first recent desktop contrast failure still needs its underlying root cause investigated. A passing rerun is not a formal manual accessibility assessment.

## Human validation checklist

Ask a first-time football fan to find a goal, follow a player, ask a question and explain why a claim was rejected. Ask a producer to fix the blocked draft, try demo approval and identify where the experience explicitly states that nothing was actually sent. Verify keyboard, mobile and screen-reader clarity at the final exact source SHA.

No observation of real fans or producers is claimed by this document.
