# Teardown policy

No cloud resources exist from this execution. There is nothing to delete in Azure.

For future deployments, retain judge access for the required judging period and obtain
owner approval before teardown. Inventory only MatchDesk-owned resource IDs, export
required evidence/backups, verify retention and remove resources within that inventory.
Never delete an entire subscription or unrelated resources. Stop recurring evaluations
and validate that cost-producing dependants have also been removed.
