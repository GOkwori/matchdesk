# Product overview

Status: design baseline; only the contract foundation is implemented.

The producer is the primary operator. The desk should reduce the distance between
raw events, an explanatory narrative and a deliberate publishing decision. Its
signature interaction is selecting a claim and seeing the supporting events on a pitch.

Success is an end-to-end, inspectable path rather than a large dashboard of disconnected
statistics. The current foundation establishes input identity, explicit clock semantics
and structural validation. Those are prerequisites, not substitutes for match intelligence.

The full acceptance scope is recorded in the [project specification](../project-specification.md).
