# Producer experience and foundation workbench

Status: workbench source authored; Next.js build, browser tests and visual review pending.

The foundation screen permits an event JSON edit and calls the actual API validator.
It labels structure acceptance separately from evidence truth and clears stale output
on edits. A bounded request timeout exposes failure rather than substituting success.
There are no inactive producer buttons or fabricated live statistics.

The intended producer console adds a match strip, pitch, momentum history, content
queue, evidence drawer, agent activity and broadcast/fan preview. Selecting evidence
must synchronise narrative and pitch context using one replay/window identity.

Keyboard focus, named inputs, live-result announcements, error alerts and narrow-screen
layouts are authored. These do not establish WCAG compliance: keyboard, screen-reader,
contrast and automated accessibility tests remain required on the running application.

System fonts avoid remote assets at this stage. Original cyan/navy styling is defined
locally. Tailwind integration and its exact lock remain open; the foundation uses
plain CSS rather than claiming that an uninstalled build plugin has run.
