# Project pitch

I am building MatchDesk, an explainable AI football production desk. My aim is to turn
synthetic match events into stories a producer can inspect before publishing, with
each factual claim linked to its supporting events and calculations.

The planned design combines deterministic Python analytics, Microsoft Agent Framework
and Foundry specialists, and a Next.js producer interface. The foundation currently
implements contract validation and source identity; the live narrative, approval and
broadcast workflow remains in development.
