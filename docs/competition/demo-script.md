# Demo script (2 minutes)

Recorded from the studio's guided tour on the synthetic Northbridge v Riverside replay.
Narration is first person.

| Time | Screen | Action | Narration |
| --- | --- | --- | --- |
| 0:00 | Home | Show the headline | "A wrong number in a match graphic goes out in seconds. MatchDesk lets AI draft the football story, but only code can certify a fact, and only a person can publish it." |
| 0:12 | Overview | Click **Claim 59% instead** | "Here is the idea in one click. Northbridge had 57.96% of possession. Claim 59%, and it is rejected: recomputed from all 1,421 events of this synthetic match." |
| 0:27 | Moments | Open the 58′ goal | "Moments are found by rules and tied to the events that prove them: a corner, then Okafor's header fourteen seconds later." |
| 0:39 | AI insights | Step through the **Recorded live run**, then click **Rehearsal** | "This is a real run of four specialist agents on Microsoft Foundry. Code rejected a malformed answer, the reviewer dropped an unchecked sentence, and the verifier confirmed the scorer. In the rehearsal the writer claims 60% possession; the verifier sends it back, and the revision says 58%." |
| 1:02 | Evidence | Show the calculation | "The proof: the formula, the events and the result, checked on the server and again in your browser." |
| 1:12 | Composer | Remove the season claim, **Mark as opinion** on the interpretation; then change 58 to 60 | "Fix the draft and it becomes eligible. Change a number, and it fails as I type. The sentence is checked, not just the data behind it." |
| 1:30 | Ask MatchDesk | Press **Ask**; ask "Who scored the second goal?", then "How many headers did Okafor score?" | "Ask the match anything. Every figure is computed and verified before it is shown, and when it can't check something, it says so instead of guessing." |
| 1:46 | Fan story | Switch to Español | "Fans get the verified story in their language, with every check shown. Approval stays with a human producer." |
| 1:56 | Home | End | "AI-assisted. Verified. Human-led." |

AI insights opens on the recorded live run; its banner names the provider and the date.

in Settings so the composer starts with D-031 blocked.
